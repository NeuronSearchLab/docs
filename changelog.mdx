Product changes are grouped by the task they help you complete. This is a curated record of selected updates; use the linked guides for current behaviour and configuration.

## November 2026

### Context groups

Organize related recommendation contexts into a group, arrange their rails and request the group together. Each rail retains its context and request attribution. See [Context groups](/console/context-groups) and [recommendation sets](/api-reference/endpoint/get-recommendation-sets).

## October 2026

### Several recommendation rails in one request

Recommendation sets let an application fetch multiple placements together, inspect each set's result and attribute interactions to the correct rail. The [recommendation guide](/integrate/recommendations) explains batching and partial failures; check your [SDK reference](/sdk/overview) for method availability.

### Website recommendation display

The website embed supports several placements on one page, theme options and handling for empty results and items without images. See [Website embed](/embed).

## September 2026

### Search signals

Search queries and result item IDs can be recorded as behaviour signals. See [Search](/integrate/search) and [Events](/integrate/events) for payloads and attribution.
