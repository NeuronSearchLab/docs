## October 2026: recommendation sets

The client libraries gained methods for requesting multiple recommendation sets and preserving attribution for each rail. See the [SDK comparison](/sdk/overview) and the reference for [JavaScript](/sdk/introduction), [PHP](/sdk/php), [Next.js](/sdk/nextjs) or [Swift](/sdk/swift).

Check the version you have installed before adopting a newly documented option. Framework wrappers and native libraries have different authentication, batching and attribution behaviour; those differences are called out in each reference.
