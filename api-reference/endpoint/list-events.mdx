---
title: "List events"
description: "List ingested events with cursor pagination."
openapi: "/api-reference/openapi.json GET /v1/events"
---

List recorded event occurrences. Event-type configuration is separate: use [Events in the console](/console/events) or the Platform API to create labels and weights.

Use the filters and pagination below to inspect a user's or item's history. A search event can have no item; its query and result IDs describe the search. See [Events](/integrate/events) for the ingestion contract.
