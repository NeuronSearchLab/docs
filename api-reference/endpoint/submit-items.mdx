---
title: "Create items"
description: "Create catalog items for recommendation."
openapi: "/api-reference/openapi.json POST /v1/items"
---

Create one item or an array of items. NSL generates each integer item ID; do not provide your own top-level ID.

Set `metadata.source_item_id` to a stable source identifier when repeated imports should update the same item. The same source ID within your workspace resolves to the existing NSL ID. Other metadata keys, such as a custom `sku`, do not enable this matching by themselves.

Store the returned integer IDs for event tracking, related-item requests and direct updates. New items are active; change availability with [Update item](/api-reference/endpoint/update-item).

See [Catalogue](/integrate/catalogue) for ingestion paths and field guidance.
