---
title: "Delete item"
description: "Delete a catalog item."
openapi: "/api-reference/openapi.json DELETE /v1/items/{item_id}"
---

Delete an item by its NSL integer ID. Remove it from your application's recommendation display and source synchronization if it should not be re-imported.

For an out-of-stock or temporarily unavailable item, use [Update item](/api-reference/endpoint/update-item) with `active: false` so you retain the record. See [Catalogue](/integrate/catalogue).
