---
title: "Update item"
description: "Update an existing catalog item."
openapi: "/api-reference/openapi.json POST /v1/items/{item_id}"
---

Update the fields supplied for an existing item. Despite the SDK method name `patchItem`, its standard wire request uses **POST** on this item URL.

Set `active` to `false` to stop recommending the item while retaining it. Prefer this for temporary unavailability. Send the complete metadata object you intend to retain when replacing metadata, including `source_item_id` if you use repeat imports.

See [Catalogue](/integrate/catalogue#update-and-retire-items) and your [SDK reference](/sdk/overview).
