---
title: "Retrieve event"
description: "Retrieve a single ingested event."
openapi: "/api-reference/openapi.json GET /v1/events/{event_id}"
---

Retrieve one recorded event occurrence by its event-record ID. This is different from `event_id` in an ingestion payload, which identifies the configured event type.

Inspect its user, item, context and request attribution when debugging tracking. See [Events](/integrate/events) and [Explainability](/console/explainability).
