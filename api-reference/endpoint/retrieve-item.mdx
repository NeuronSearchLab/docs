---
title: "Retrieve item"
description: "Retrieve a single catalog item."
openapi: "/api-reference/openapi.json GET /v1/items/{item_id}"
---

Read an item by its NSL integer ID, including its current metadata and availability. A source SKU or slug is not a substitute for this ID.

Use [Update item](/api-reference/endpoint/update-item) to change it or [Catalogue](/integrate/catalogue) to plan synchronization.
