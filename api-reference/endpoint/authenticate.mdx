---
title: "Create access token"
description: "Exchange SDK credentials for a short-lived access token."
openapi: "/api-reference/openapi.json POST /oauth2/token"
---

Exchange [SDK credentials](/integrate/authentication) for a Core API bearer token. Use HTTP Basic authentication with your client ID and secret, and send `grant_type=client_credentials` as form data.

Cache the returned token and use `expires_in` to schedule renewal. Do not request a new token for every API call. Keep the client secret and access token on a trusted server. Platform API keys and embed publishable keys are different credential types.

JavaScript, PHP and Next.js can manage this exchange for you; see [Choose an SDK](/sdk/overview).
