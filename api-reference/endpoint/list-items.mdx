---
title: "List items"
description: "List catalog items with cursor pagination."
openapi: "/api-reference/openapi.json GET /v1/items"
---

List items in your workspace. Use the filters below to narrow the result, and follow the returned pagination information instead of assuming the first page is the complete catalogue.

Item IDs are NSL-generated integers. Keep a mapping to your source IDs if your application sends events. For an operator's searchable catalogue, use [Items](/console/items).
